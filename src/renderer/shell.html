SSH 反向隧道（推荐：复用 22 端口，服务器无需开新端口）

用 SSH 私钥建立 Mac→服务器的反向隧道，域名经服务器 Nginx 反代到穿透端口。适合腾讯云轻量等默认只放行 22/80/443 的服务器（无需改防火墙）。

frp 内网穿透（备用：需服务器开 7000 端口）

在你自己的服务器上跑 frps，Mac 跑 frpc 自动连接，域名经服务器 Nginx 反代到穿透端口 —— 稳定不受 trycloudflare 干扰。

📋 服务器端安装脚本（SSH 登录服务器后执行，一次配置） 
# 在腾讯云服务器上执行（Ubuntu/Debian）：
sudo bash setup-frps.sh <你的frp token> dsh.example.com 8080

# 完整脚本：项目 scripts/setup-frps.sh
# 它自动：安装 frps → 注册系统服务(开机自启) → 装 Nginx →
#         签 Let's Encrypt 证书 → 配置 HTTPS 反代到 8080

# 部署前还需：
# 1) DNS：example.com 添加 A 记录 dsh → 服务器公网 IP
# 2) 腾讯云控制台 → 防火墙：放行 TCP 7000（frps）和 TCP 80/443

第三方服务（MCP）

这里接入第三方服务（如云手机 / 云电脑 / 外部 API 工具），通过 MCP 协议让 Agent 获得其能力。
前提：服务方需提供 MCP server —— HTTP 方式填 URL（如 https://xxx/mcp），本地方式填启动命令（如 npx @some/mcp-server）。
添加后点「保存并重启服务」，Agent 的工具列表里就会出现该服务的工具。

说明：native 在 Mac 本机弹系统目录对话框，选择结果自动回传给手机/隧道页面 —— 本地和远程都适用，是修复 host.pickDirectory 403 的正确方式。auto 在远程会回退到 browse（导致 403），browse 仅供页面内浏览服务器目录。启动公网隧道时会自动切为 native 并重启 harness。改完点下方「保存并重启服务」。
